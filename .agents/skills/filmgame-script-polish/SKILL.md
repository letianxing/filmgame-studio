# 剧本语言与可拍性润色

从用户指定段落做局部第二遍审读，先保留信息、人物、情节和已定语气，再处理表达。把不可拍的心理说明标出来，给出局部可见行为建议；若任务只限对白，动作建议单列，不直接写进原稿。

检查动作描述是否具体、对白是否自然、相邻段落是否重复同一信息，以及沉默或短反应是否更有效。不要为了“去AI味”加入方言、俚语、粗口、夸张修辞或没有依据的生活细节。

交付修订片段与少量理由，标明哪些只是建议。格式按项目语言和稿件体例，不强制英文大写角色名或西文页码。原系统中的通用写作全库不是本模块运行依赖；本适配版只承担电影剧本润色。

## 项目边界与来源

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。

本文件是第一方项目适配，不是上游原文副本。方法来源：[固定版本的 script-writing](https://github.com/Deupaxx/EveryDay-Writer/blob/cac4418fb82c92894d6f89e0c3072b16a830eae3/skills/script-writing/SKILL.md)。许可证和引用边界记录在仓库根目录 `third_party/screenwriting/`；未打包上游书籍、影视剧本引文或参考语料。
