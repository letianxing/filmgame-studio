# 影片结构与因果

把主要事件排列为“处境 → 决定 → 后果 → 新处境”，让每次重要转折有可追溯的触发。先明确用户指定的结尾与不能动的事实，再评估哪些铺垫和人物选择能支撑它。

短片按实际时长取必要的变化，长片按段落处理主线与副线；不套固定页码、15拍或40场，也不要求反高潮作品出现中心对决。非线性作品分别检查故事发生顺序与观众得知顺序。

交付按用户需求选择：段落大纲、因果节拍表或结构诊断。节拍用具体事件和决定，注明人物、前因、后果及信息释放；不要用“气氛升级”替代发生的事。

检查伏笔是否有回收或有意悬置、冲突是否重复、解围是否依赖未铺垫的人物或能力、旁线是否改变主线理解。对有意停顿与失败结局给出作品内部依据，不强行改成胜利。
