# 正式剧本格式与改编

遵循用户指定的交付格式；未指定时，中文影片用清晰场号、内外景、地点、时间、可拍动作与人物对白。持续工程以项目 JSON 为权威，Markdown 或 Fountain 是可重新导出的阅读稿。

动作写可见可听的现在时事件，心理用表演或行为承载。画外对白、旁白和同场不入画的人声区分清楚。中文稿的页数不能机械按一分钟折算，时长应有对白和动作估算依据。

改编先列必须保留的事件、人物、关系、视角和结局，注明原素材与本次新增提议。将叙述性信息转成戏剧行动；引用文本与可用权利分别记录，不照搬第三方示例台词或书籍摘录。

交导演时提供稳定场次、人物、动作、逐字对白、时间意图和未解决问题；只有另行要求导演稿才增加镜头与运镜。需要 PDF/DOCX 时调用可用的文档工具并做实际排版检查，不凭文件扩展名声称导出成功。

## 项目边界与来源

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。

本文件是第一方项目适配，不是上游原文副本。方法来源：[固定版本的 sw-format-adaptation](https://github.com/jtydhr88/screenwriting-skills/blob/51115f18d160aa8b2ac5813e4432b6f0b425358f/plugins/screenwriting/skills/sw-format-adaptation/SKILL.md)。许可证和引用边界记录在仓库根目录 `third_party/screenwriting/`；未打包上游书籍、影视剧本引文或参考语料。
