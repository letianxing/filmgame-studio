# 故事前提与主题

从用户给的事件或角色出发，写清主人公的可见目标、障碍、风险和关键选择。主题通过选择造成的后果显现；不要让人物替作者解释道理。

工作时分清：人物想得到的东西、人物不愿面对的问题、观众为什么在乎。对已有结局反向寻找成立的因果，不擅自改掉已锁定的结局。历史材料分别标明史料、传说和虚构，未查证的细节保持待确认。

按请求交一句话故事、简短梗概、核心选择与待定项。只有创作方向确实开放时才比较少量方案，不自动制造多个结局。

自检：故事能否靠人物行动展开？障碍是否与主角有直接关系？代价是否在故事中可见？高潮结果有没有前面的选择支持？不要把主题词当剧情，也不要把道德判断套在每种题材上。

## 项目边界与来源

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。

本文件是第一方项目适配，不是上游原文副本。方法来源：[固定版本的 sw-premise-theme](https://github.com/jtydhr88/screenwriting-skills/blob/51115f18d160aa8b2ac5813e4432b6f0b425358f/plugins/screenwriting/skills/sw-premise-theme/SKILL.md)。许可证和引用边界记录在仓库根目录 `third_party/screenwriting/`；未打包上游书籍、影视剧本引文或参考语料。
