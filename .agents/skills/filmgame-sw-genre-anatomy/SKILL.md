# 类型预期与叙事选择

先从用户故事判断主要观看体验，而不是仅按时代或画风命名类型。国风、写实和三维动画是视觉或文化方向，不自动等于仙侠、战争或爽剧。

列出当前类型需要建立的期待、关键不确定性、承诺的回报以及故事自己的变体。混合类型时说明哪条主导情绪和结局，其他类型怎样支撑它。与用户锁定的事实冲突时改方案，不能改事实去满足模板。

输出短的类型策略与具体场次建议。检验世界规则是否一贯、悬念与揭示是否公平、动作是否改变人物处境、情感回报是否由行为积累。避免复制既有作品的角色、情节或台词，不把通用类型规则当版权授权。
