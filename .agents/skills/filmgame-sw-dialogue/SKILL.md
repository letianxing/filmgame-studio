# 人物对白与潜台词

逐个说话人明确此刻想让对方做什么、准备隐瞒什么、为何选择当前措辞。人物可以试探、回避、安慰、交换条件，也可以真诚表达；不要把每句都改成冲突或隐喻。

从职业、关系、经验和当下压力区分词汇、句长、节奏与沉默。遮去姓名后尝试辨认说话者；若仍相同，修改语言选择而不是给每人加口头禅。

删去双方明知而专为观众解释的部分，除非说出它本身是人物的策略。允许有功能的重复、停顿、日常交流与旁白；不把某几个词列成一刀切禁用词。避免连续金句。

对白润色任务只改被点名的台词与必要的局部标点，不新增角色、事件、动作、关系、结局或摄影方案。动作有问题另列建议，得到相应任务后再改。给出修订台词和短的改动理由；读起来是否自然、是否说得完需另核。

若持久化修订，使用 screenplay commit 的 dialogue scope，将候选与当前版本比较，确保动作和其他场次保持原样。

## 项目边界与来源

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。
