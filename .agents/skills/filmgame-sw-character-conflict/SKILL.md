# 人物与冲突

只研究足以影响当前故事的特征。为主要人物写：外在目标、内在缺口、当前策略、不愿付出的代价、关系中掌握或缺少的力量。用一项可见选择证明特点，避免只有形容词的小传。

对手可以是人物、制度、环境或主角自身。说明双方为何此时相遇、为何不能轻易退出，以及彼此选择怎样改变对方处境；不强制反派邪恶、主角胜利或每个人都有正向成长。

人物变化要有触发与连续行为。已定的姓名、身份、亲属关系与结局作为 lockedFacts 保护；新的背景或心理解释标为建议。人物缺失的信息与观众知道的信息分开记录。

交付人物工作表和关键关系冲突，按片长缩放深度。检查配角是否重复功能、行动是否符合其知识与资源、转变是否只发生在台词中。

## 项目边界与来源

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。
