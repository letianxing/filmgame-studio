# 人物选择与故事联动

从主角的弱点、目标、策略、对抗和关键选择检查全片连接。追踪一次失败如何改变下一次行动，以及新信息是否迫使人物重新选择，而不只是增加解释。

审视对手的独立行动和双方价值差异。高潮是否检验了主角前面形成的能力、错误或代价？结尾是否能看到选择的后果？允许失败、拒绝改变、开放或反高潮结局。

交付一张“场次/信息变化/人物决定/后果”对应表和最小修改建议。先检查当前稿，再补缺口，不默认追加假盟友、死亡体验或固定数量的步骤。短片不强套长片组件，群像不硬造唯一主角。
