# 分场与戏剧行动

先确定这场在整片中的职责以及入场时观众已知的信息。写清人物当前目标、阻力、所用策略和离场时改变了什么。变化可以是关系、信息、处境或观看角度，不必每场都爆发争执。

优先用能看见、能听见的动作表达心理。道具承担具体叙事作用并保持位置与持有人连续。对白围绕人物当下要完成的事展开，背景信息只在有动机的行动中释放。

交付分场时用稳定 scene ID、地点/内外/日夜、出场人物、行动、对白与转折。时间估算是创作意图，需对白朗读和动作时长复核，不把中文页数当准确分钟。

相邻场景检查信息、动作与声音如何衔接，保留必要的铺垫和反应。用户只改一场时不扩散到其他场；必要的上游问题列为建议。摄影细节交给导演分镜，除非用户明确要导演稿。

在 FilmGame Studio 中使用本模块，遵守仓库 AGENTS.md 和用户已明确的创作范围。持续项目遵循仓库根目录 `docs/SCREENWRITING_WORKFLOW.md` 的 JSON 校验、版本与导出契约；局部口头建议不强制建立项目。只有用户授权的制作请求才进入付费媒体阶段。
