# 概念图与视频局部修复

## 目标与当前边界

保留已认可的导演表现，只修用户指出的缺陷。局部修复是一个有预算、时间上限、输入版本和人工验收的生产任务，不能成为无限返工循环。

当前已实现：工具能力清单、版本绑定的修复计划 API、计划持久化、输入与限额检查。**尚未实现自动修图、自动视频合成、专用 UI 和自动提交候选**。下列算法的节点试验结果不能当成平台级生产能力；计划中的限额尚未绑定执行器，不宣称已自动执行限额。

## 工具选用

| 工具/方法 | 用途 | 必须检查 | 当前成熟度 |
|---|---|---|---|
| imagegen / 即梦局部参考编辑 | 删除多余人物、改衣装道具、生成干净背景底图 | 编辑范围外变化，脸/衣装/光照/人数，尺寸和透视 | 已有人审参考图；不保证像素锁定 |
| OpenCV SIFT + RANSAC | 底图与原帧几何配准、估计相机运动 | 足够分散的静态背景特征、误匹配、视差 | 本地试验；不能拿配准分数证明美术通过 |
| DIS 光流 + 动态遮罩 | 局部补片跟随遮挡边缘 | 遮挡/重新露出、边缘游动、人物冻住、动作传播到背景 | 试验性；非通用一键视频修复 |
| FFmpeg | 抽帧、视频合成/编码、保留原声、技术验证 | 实际可用编码器、逐帧 PTS、尾帧时长、音频包与裁切元数据 | 工具可用；导出仍需逐项验证 |
| Seedance 对应短镜头重制 | 局部合成无法修复的复杂姿势/接触/运镜 | 人审参考、实时价格、连续性、复用原剪辑和声音的可行性 | 需要报价及人审；视频参考不等于精确局部编辑 |

## 嵌入节点制作流程

1. 从审片意见建立具体缺陷，绑定原素材 runId、SHA、区域、镜头时间段和必须保留的内容。原片可作为返工源，不因引用而获得采纳状态。
2. 先选最小可行修复范围：单图局部编辑 → 单镜动态补片 → 必要短镜重制。不要强行用补片处理复杂肢体接触，也不要未经检查整段重生。
3. 单独预算：积分上限、墙钟时间、尝试次数。零即梦积分不等于零外部费用；未确认费用记 unknown/null。达到当前计划上限时给出已有结果和取舍，不静默加额。
4. 使用原帧生成底图。底图经人审后仍只是参考；背景重建不得改变光源。自动修改到其他士兵/人物时须明确告知，不假称仅改一人。
5. 分镜处理动态遮挡，保留未修区域的原始表演。每个切点重新建立遮罩，检查同一对象是否在后镜重现。新露出的背景人物不能像静止纸片。
6. 技术审查与视觉审查分开：媒体可解码、尺寸/帧数、精确 PTS/帧时长、原声包/时间/尾部裁切、切镜、接缝、人物与光影。ASR 仅协助字幕对齐，不等于听音验收。
7. 新候选进入现有人审，不自动覆盖旧采纳版。只有精确候选 SHA 经人工采纳后才进入版本清单、runtime 组装和整节点验收。
8. 最终采纳后核依赖再清理被替代和拒收媒体，留 SHA、费用、根因、删除回执。仍在使用的源/参考和唯一工作候选保留。

## API（计划阶段，不发起付费任务）

`GET /v1/comic/projects/:id/local-repair-capabilities`

`POST /v1/comic/projects/:id/plan-local-repair`

请求字段：`revision, runId, sha256, method, defect, region, preserve[], userDirection, limits`。
视频还需 `interval: {startSeconds, endSeconds}`，不得超出源视频。`limits` 为
`{maxCredits, maxMinutes, maxAttempts}`，不能留空或非有限数值。方法取能力清单中的 id。

返回计划 `PLANNED_NOT_EXECUTED`，存入项目 `localRepairPlans`；不会修改源 run、引用、采纳版本或开启生成。已删除或 SHA 改变的源会拒绝；不从历史拒收记录自动恢复媒体。执行器后续接入时必须复用现有 harness、成本账本、任务锁和候选审核，不能直接把计划标成执行成功。

## 已踩过的坑

- 静帧修好不代表视频修好；生成底图经常缩放/重绘外围，禁止直接全帧替换动态演员。
- 同一段原片与后续重做版本的字幕时间不同，字幕必须绑定源 SHA。
- 默认原生数值库线程池可能占用大量提交内存；在导入库前限制线程，再执行原有内存准入。不能降低保护线冒充解决问题。
- 当前机器 FFmpeg 未提供 libx264，实际可用编码器需现场查询；不得换文件名重置失败计数。
- 音频包内容和 PTS 一致，仍可能尾包裁切时长不同；编码成功和单纯 stream-copy 不足以证明时间无损。
- 禁止把本地试验片当作已审核正式素材；技术检查通过也不自动获得人审采纳。
