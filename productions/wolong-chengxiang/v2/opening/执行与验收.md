# 当前执行稿与来源记录

原著：罗贯中《三国演义》第四十三回。文言核心问答保留，互报姓名与议论为原创衔接。
本段不是正史实录；角色年龄按208年前后研究设定，服饰与厅堂为汉末轮廓的艺术设计，并非已完成逐件考古复原。

## 生成前调整
人物板被供应商以“可能含真人”拒绝。最终请求不提交该人物图片，仅提交无人厅堂母版；人物用原创动画文字设定生成。首段成片的人物与声音若通过审查，将成为续段的真实参考。
原计划末尾4秒视频+尾帧续写，但本地视频编码不被API接受，远程存储返回502，且生成视频中的人物静帧也被判可能含真人。最终改为第一段原始生成视频的HTTPS地址作参考，后续不再提交被拒绝的静帧。参考任务非无缝延长，需审查剪辑接点；按实际30秒视频输入计费。

## 物理审片重点
- 进门时脚底与地面接触，人在走道里走，不穿过柱案。
- 拱手仅小幅动作，不新增肢体；胡须与衣袖分离。
- 跪坐的身体在低案后空席，膝盖不能进入木案；衣摆遵循重力，不粘住案面。
- 杯盏握持和竹简落案有真实接触，不空手凭空多出道具。
- 群体反应错开，不让全堂同时做相同动作；画外人声不让听者同步动嘴。
- 每段抽帧覆盖并重点加密动作切点；自动技术检查不等于无穿模保证。

## 120秒时间线

### 1. arrival（0–30秒目标）
- 0–7：35mm稳定后侧跟随；鲁肃引孔明从右侧门廊进入中央走道，衣袖轻摆，众人低语自然停下。
- 7–12：孔明主观视角慢移；看向靠右远处的张昭、其下首顾雍、左侧近处空客案。
- 12–20：50mm鲁肃与孔明双人中景；鲁肃微侧身介绍，孔明挺身站在走道，手在袖中。
- 20–26：65mm孔明胸口以上近景；孔明拱手见礼，小幅俯身，抬眼时沉静有礼。
- 26–30：65mm张昭反应；张昭抬眼，微微还礼，审视来客，不冷笑。
- 鲁肃：此乃刘豫州帐下，诸葛孔明先生。
- 孔明：亮，见过诸公。

### 2. introductions（30–60秒目标）
- 0–6：50mm三人关系中景；孔明仍站走道，鲁肃轻示张昭首席，张昭收拢竹简。
- 6–11：65mm张昭；张昭抬眼报姓名，语气温和而疏离。
- 11–18：65mm顾雍近中景；鲁肃示张昭下首顾雍，墨绿袍顾雍拱手。
- 18–23：65mm孔明；孔明转向顾雍还礼，两侧人各自回应，不同时整齐动作。
- 23–30：50mm客席关系；张昭示意空席，鲁肃退半步让开走道，孔明走到左侧近处案后的空席前停住。
- 鲁肃：这位，便是张子布先生。
- 张昭：张昭。久闻先生之名。
- 鲁肃：这位是顾元叹先生。
- 顾雍：孔明先生。
- 孔明：幸会。
- 张昭：先生请坐。

### 3. first-question（60–90秒目标）
- 0–8：50mm客席侧面；孔明在案后空席整衣跪坐，木案始终在身体前方，不穿案；鲁肃留在他后侧站立。
- 8–12：85mm张昭的手与竹简；张昭手中简册落在木案上，手仍自然可见，无额外手指。
- 12–27：65mm张昭胸口以上近景轻缓推近；张昭说话前半自谦，后半加重管乐，视线朝画左孔明。胡须轻动但不扭曲，句末嘴合。
- 27–30：85mm孔明反应；孔明认真听完，抬眼平静，看向画右张昭。
- 张昭：昭乃江东微末之士，久闻先生高卧隆中，自比管、乐。此语果有之乎？

### 4. answer-reactions（90–120秒目标）
- 0–7：85mm孔明；孔明轻轻抬眼，平静答复，不夸张大笑，脸与前段一致。
- 7–12：65mm一名灰袍士人与杯盏；一名灰袍士人端杯动作停住，杯不离手，向邻席稍偏头低语；邻席只轻微抿嘴。
- 12–16：65mm顾雍；顾雍敛去客套，认真看孔明，眼神更专注；背景议论轻微。
- 16–20：65mm鲁肃；鲁肃眉心略紧，想上前却克制停住，不抢答。
- 20–25：65mm张昭；张昭等细语落下，手指在简册边停住，神情由客套转为严肃。
- 25–30：85mm孔明；孔明坐稳客席，听见质疑也不四处张望，目光仍对张昭。最后留环境声与余韵。
- 孔明：此亮平生小可之比也。
- 灰袍士人：小可之比？
